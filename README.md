# Delicate Glow Up

本次更新（V19）改版

修復與優化細節：

滑動切頁干擾排除：現在在「飲食」分頁滑動食物下拉選單（Autocomplete List）時，不會再被誤判為左右滑動切換分頁了，找食物更順手。

補登紀錄經驗值開放：解除了「必須是今天操作才能獲得 EXP」的限制。如果使用者切換到昨天的日期並補上紀錄，寵物一樣會根據那些動作獲得對應的 EXP，鼓勵使用者回頭補齊數據。

寵物互動防呆 (防連點卡頓)：在寵物的「餵食、特技、休息」動作加上了防止連點的機制（利用現有的 isInteracting 狀態）。在動畫撥放完畢前點擊無效，避免短時間內噴出幾十個表情符號導致畫面卡頓。

日期點擊提示優化：在頂部的日期文字旁加上了一個半透明的「小日曆圖示 (📅)」，並且在點擊時會有視覺回饋，讓新使用者一看就知道「這裡可以點開換日期」。
