# Delicate Glow Up (V9 超巨大食物資料庫擴充版)

這是一個專為您量身打造的「亮粉色 X 冷酷黑」風格日常紀錄 Web App。這次為飲食紀錄加入了高達 150 種以上的智慧輔助熱量資料庫！

## 全新智慧飲食庫大升級 (約 150+ 項)：
- 涵蓋各種異國料理與台灣在地美食，輸入關鍵字即可一鍵帶入名稱與熱量：
  - **台式/主食**：滷肉飯、牛肉麵、大腸麵線、水餃、臭豆腐、鹹酥雞...
  - **日式料理**：生魚片、牛丼、豬排咖哩飯、豚骨拉麵、章魚燒...
  - **韓式料理**：石鍋拌飯、辣炒年糕、部隊鍋、烤五花肉、海鮮煎餅...
  - **西式/義美**：青醬義大利麵、瑪格麗特披薩、沙朗牛排、美式漢堡、潛艇堡...
  - **泰式/東南亞**：打拋豬、月亮蝦餅、綠咖哩雞、越南河粉、海南雞飯...
  - **早餐/輕食**：各式蛋餅、漢堡、飯糰、燕麥、沙拉...
  - **甜點/飲料/水果**：珍珠奶茶、拿鐵、燕麥奶、馬卡龍、提拉米蘇... (應有盡有！)

## 部署到 GitHub Pages 的步驟：

1. **進入您的 Repository**：
   - 登入您的 [GitHub](https://github.com/) 帳號，進入 `delicate-glow-up` 專案。

2. **上傳覆蓋檔案**：
   - 點擊 `Add file` -> `Upload files`。
   - 將解壓縮後的 **`index.html`**、**`manifest.json`** 與您之前的 **`icon.jpg`** 三個檔案一起拖曳到上傳區塊。
   - 點擊 `Commit changes` 保存。

3. **手機更新 APP**：
   - **請將原本手機桌面上的 APP 刪除**。
   - 打開手機瀏覽器，重新進入您的 GitHub Pages 網址。
   - 重新點擊分享按鈕並選擇「加入主畫面」。
