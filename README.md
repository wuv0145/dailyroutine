# Delicate Glow Up 

這是一個專為您量身打造的「亮粉色 X 冷酷黑」風格保養品紀錄 Web App。只要將這些檔案上傳至 GitHub 並啟用 GitHub Pages，即可在手機上像 App 一樣使用！

## 部署到 GitHub Pages 的步驟：

1. **建立新的 Repository**：
   - 登入您的 [GitHub](https://github.com/) 帳號。
   - 點擊右上角的 `+` 建立一個新的 Repository（例如命名為 `delicate-glow-up`）。
   - 將 Repository 設定為 Public。

2. **上傳檔案**：
   - 建立完成後，點擊 `uploading an existing file`。
   - 將解壓縮後的 `index.html`、`manifest.json` 與您剛剛下載的 `icon.jpg` 三個檔案一起拖曳到上傳區塊。
   - 點擊 `Commit changes` 保存。

3. **開啟 GitHub Pages**：
   - 進入該 Repository 的 `Settings` 頁籤。
   - 在左側選單找到 `Pages`。
   - 在 `Build and deployment` 區塊，選擇 `Deploy from a branch`。
   - `Branch` 選擇 `main`，然後點擊 `Save`。

4. **完成部署！**：
   - 等待約 1~2 分鐘，GitHub 會在頁面上方顯示一串網址（例如 `https://你的帳號.github.io/delicate-glow-up/`）。
   - 用手機瀏覽器打開這個網址。
   
5. **加到手機主畫面 (PWA - 漸進式網頁應用程式)**：
   - **iOS (Safari)**：點擊瀏覽器下方的分享按鈕（方塊向上箭頭），滑動並選擇「加入主畫面」。
   - **Android (Chrome)**：點擊右上角的三個點選單，選擇「加到主畫面」或「安裝應用程式」。
   - 💡 **提示**：加入主畫面後，您可以像一般原生 App 一樣，從手機桌面全螢幕直接開啟它！所有的編輯與打卡紀錄會自動儲存在您手機瀏覽器的本地端 (Local Storage) 中。
