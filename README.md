# Delicate Glow Up

本次更新（V17）特色寵物系統大改版：

🏰 獨立特色生態場景 (Biome)：

每隻寵物都有各自專屬、超夢幻的生態背景！

🐧 小企鵝配「冰雪城堡」、🐦 綠繡眼配「森林派對」、🐌 小蝸牛配「奇幻花園」、🐑 小綿羊配「雲朵樂園」、🐱 星霓貓配「霓虹夜幕」、🐕 幻光犬配「宇宙探險」。

背景會隨著你寵物的不同切換專屬的霓虹漸層與裝飾特效，看起來更有伴侶專屬基地的儀式感！

🏷️ 寵物命名系統：

在寵物卡片左上方，你可以自由幫寵物改名字！

點擊小筆（編輯）圖示就可以輸入你想叫牠的暱稱（如「圓圓」、「酷皮」等），並同步保存在備份檔內。

👕 夥伴更衣室 (裝扮功能)：

隨著寵物等級與你的連續天數提升，能解鎖各種特色配件：

Level 2 解鎖：🕶️ 酷炫墨鏡

Level 3 解鎖：🎩 紳士帽、🎀 蝴蝶結

Level 4 (MAX) 解鎖：👑 皇冠

連續 3 天以上解鎖：🎒 旅行小背包

連續 7 天以上解鎖：✨ 幻彩星光

配件會直接「戴」在你的 EMOJI 上！

📊 今日狀態連動 (飽食、顏值、水分)：

新增三大狀態條，與你的生活數據直接連動：

💧 飽水度：跟著你「喝水量」成長。

✨ 顏值感：跟著你今天完成的「保養清單比例」成長。

🍖 活力值：跟著你今天記錄的「飲食多樣性」成長。

隨時能查看你的習慣有沒有好好養成，養成得越好，寵物看起來就越有活力、越亮眼！

🧭 冒險探險 (尋寶遊戲)：

每天可以派牠出去進行一場 8 秒的「冒險探險」！

倒數結束後，牠會為你隨機帶回一些可愛的日記描述或驚奇小寶物（如✨亮麗寶石、🌿蘆薈嫩葉、🥛補水泉水，甚至是幸運草），並幫你額外賺取 +5 EXP 經驗值！
