# Delicate Glow Up (V7 互動摸摸升級版)

這是一個專為您量身打造的「亮粉色 X 冷酷黑」風格日常紀錄 Web App。加入了超萌的互動功能！

## 全新互動功能：
- **可以摸摸寵物啦！** 👆：現在只要在首頁「點擊寵物」，牠就會開心地放大、跳躍，還會噴出愛心 ❤️ 動畫！
- **專屬寵物語音泡泡 💬**：每隻寵物都有自己專屬的台詞！像是小企鵝會說「今天好冷，要抱抱❄️」，星霓貓會傲嬌地說「只給你摸喔。」
- 所有前面的功能（早晚變色、連續打卡火焰、每日隨機語錄、滿級隱藏冰藍主題）全數保留！

## 部署到 GitHub Pages 的步驟：

1. **進入您的 Repository**：
   - 登入您的 [GitHub](https://github.com/) 帳號，進入 `delicate-glow-up` 專案。

2. **上傳覆蓋檔案**：
   - 點擊 `Add file` -> `Upload files`。
   - 將解壓縮後的 **`index.html`**、**`manifest.json`** 與您之前的 **`icon.jpg`** 三個檔案一起拖曳到上傳區塊。
   - 點擊 `Commit changes` 保存。

3. **手機更新 APP**：
   - **請將原本手機桌面上的 APP 刪除**。
   - 打開手機瀏覽器，重新進入您的 GitHub Pages 網址。
   - 重新點擊分享按鈕並選擇「加入主畫面」。
