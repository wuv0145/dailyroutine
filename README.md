# Delicate Glow Up (V5 擴充寵物夥伴版)

這是一個專為您量身打造的「亮粉色 X 冷酷黑」風格日常紀錄 Web App。新增了多款超萌的電子寵物！

## 這次更新了什麼？
- **6 款專屬寵物大集結**：在首頁您可以隨時切換以下 6 款可愛寵物：
  - **小企鵝** 🐧 (預設)
  - **綠繡眼** 🐦
  - **小蝸牛** 🐌
  - **小綿羊** 🐑
  - **星霓貓** 🐱
  - **幻光犬** 🐶
- **重新設計的排版**：切換寵物面板升級為 3 欄式設計 (2 排 x 3 隻)，畫面看起來更整齊舒適。
- **成長機制不變**：您累積的經驗值依然是全寵物共通的，記錄日常健康就能看到牠們孵化並長大！

## 部署到 GitHub Pages 的步驟：

1. **進入您的 Repository**：
   - 登入您的 [GitHub](https://github.com/) 帳號，進入 `delicate-glow-up` 專案。

2. **上傳覆蓋檔案**：
   - 點擊 `Add file` -> `Upload files`。
   - 將解壓縮後的 **`index.html`**、**`manifest.json`** 與您之前的 **`icon.jpg`** 三個檔案一起拖曳到上傳區塊。
   - 點擊 `Commit changes` 保存。

3. **手機更新 APP**：
   - **如果您是從前幾版更新過來，請將原本手機桌面上的 APP 刪除**。
   - 打開手機瀏覽器，重新進入您的 GitHub Pages 網址。
   - 重新點擊分享按鈕並選擇「加入主畫面」。
