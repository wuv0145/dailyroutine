# Delicate Glow Up (V10 寵物獨立養成版)

這是一個專為您量身打造的「亮粉色 X 冷酷黑」風格日常紀錄 Web App。這次不僅有豐富的飲食熱量庫，還讓您的每隻寵物都能「獨立養成」了！

## 這次的重要更新：
- **獨立的寵物經驗值系統 (獨立培養)** 🐧🐦🐌🐑🐱🐶：
  - 現在每切換一隻寵物，牠們的等級和經驗值都是**分開計算**的！
  - 您可以把「小企鵝」養到滿級後，再換「星霓貓」從頭開始養。
  - 在「切換寵物」的選單中，可以直接看到每一隻寵物目前長大到什麼階段，以及牠們各自的等級 (Lv.1 ~ MAX)！
  - *如果您之前已經累積了經驗值，系統會自動把它繼承到您目前選擇的寵物身上，不會讓您的心血白費！*

## 部署到 GitHub Pages 的步驟：

1. **進入您的 Repository**：
   - 登入您的 [GitHub](https://github.com/) 帳號，進入 `delicate-glow-up` 專案。

2. **上傳覆蓋檔案**：
   - 點擊 `Add file` -> `Upload files`。
   - 將解壓縮後的 **`index.html`**、**`manifest.json`** 與您之前的 **`icon.jpg`** 三個檔案一起拖曳到上傳區塊。
   - 點擊 `Commit changes` 保存。

3. **手機更新 APP**：
   - **請將原本手機桌面上的 APP 刪除**。
   - 打開手機瀏覽器，重新進入您的 GitHub Pages 網址。
   - 重新點擊分享按鈕並選擇「加入主畫面」。
