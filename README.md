# Delicate Glow Up (V8 全面升級完成版)

這是一個專為您量身打造的「亮粉色 X 冷酷黑」風格日常紀錄 Web App。這次不僅優化了操作體驗，還加入了更強的互動感！

## 這次的重要更新：
1. **寵物大變身與獨立經驗值 🌟**：
   - 每隻寵物的經驗值 (EXP) 現在是獨立計算的！養成每隻寵物都有一份專屬的成就感。
   - 寵物與蛋的尺寸**全面放大**！並且加上了特殊的 CSS 手繪卡通濾鏡，讓它們看起來像精緻的 3D/手繪小插圖。對話框也變得更大更清楚！
2. **保養品新增「其他」選項 ✨**：在保養編輯模式中，增加了「✨ 其他」的圖示讓您可以自由填寫。
3. **健康管理升級「儲存 / 編輯」功能 💾**：現在健康數值畫面會有一個「編輯紀錄」的按鈕。填寫完按下「儲存」，畫面會變成乾淨的唯讀模式，防止誤觸。
4. **飲食「熱量自動帶入」功能 🥗**：
   - 當您在食物內容輸入常見食物（例如：蛋餅、拿鐵、雞胸肉、便當 等），系統會**自動幫您填入對應的參考熱量**！當然您也可以手動修改。
   - 總熱量統計固定在下方，清楚顯示每日攝取。

## 部署到 GitHub Pages 的步驟：

1. **進入您的 Repository**：
   - 登入您的 [GitHub](https://github.com/) 帳號，進入 `delicate-glow-up` 專案。

2. **上傳覆蓋檔案**：
   - 點擊 `Add file` -> `Upload files`。
   - 將解壓縮後的 **`index.html`**、**`manifest.json`** 與您之前的 **`icon.jpg`** 三個檔案一起拖曳到上傳區塊。
   - 點擊 `Commit changes` 保存。

3. **手機更新 APP**：
   - **請將原本手機桌面上的 APP 刪除**。
   - 打開手機瀏覽器，重新進入您的 GitHub Pages 網址。
   - 重新點擊分享按鈕並選擇「加入主畫面」。
