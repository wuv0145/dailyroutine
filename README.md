# Delicate Glow Up (V11 質感升級 & 完整操作體驗版)

這是一個專為您量身打造的「亮粉色 X 冷酷黑」風格日常紀錄 Web App。這次帶來了巨大的體驗升級，讓整體介面更清新、操作更流暢！

## V11 重大更新內容：
1. **整體質感與字體放大** ✍️：全面導入高質感的開源繁體中文字體 (`Noto Sans TC` 思源黑體)，並將所有介面的字體大小、按鈕與輸入框全面調大，看起來更舒適、清新不費力！
2. **快速切換日期** 📅：日期旁邊加入了 `<` 與 `>` 箭頭，點擊就能秒切換前一天或後一天，不再需要一直開起日曆選單。
3. **滑動切換分頁** 📱：加入手機原生的滑動手勢！只要在螢幕上向左或向右滑動，就能無縫切換「寵物、保養、健康、飲食」頁面，單手操作超順暢。
4. **保養品上下排序** 🔄：在保養分頁點擊右上角「編輯(筆)」後，每個保養品左側會出現上下箭頭，您可以根據真實的保養順序自由排列。
5. **熱量目標進度條** 🎯：在「健康」分頁可以設定您的「每日熱量目標」。在「飲食」分頁下方會出現專屬的發光進度條，今天還剩多少扣打一目了然！(超過目標會變紅色警告喔)。
6. **一鍵備份與還原** 💾：在「寵物(Home)」分頁最下方加入了資料備份功能。強烈建議您定期點擊「匯出」將 `.json` 檔案存到手機裡。未來若換手機或清除資料，只要點擊「匯入」選擇檔案，所有寵物與連續紀錄都會瞬間回來！
